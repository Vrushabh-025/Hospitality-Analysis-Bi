# Hospitality-Analysis-Bi
This project analyzes hotel booking and revenue data using Microsoft Power BI to understand hotel performance, revenue, occupancy, and booking patterns. The dashboard provides an interactive view of performance across different cities, properties, room classes, booking platforms, and time periods.

The analysis uses key hospitality metrics such as Revenue, Total Bookings, Occupancy %, Cancellation %, Average Rating, and Successful Bookings to provide a clear view of hotel performance and booking trends.

📌 Dashboard Features

The dashboard includes an overall performance report along with separate Revenue Analysis and Booking Analysis pages. It allows users to explore revenue and bookings by city, hotel, room class, booking platform, and time period.

Key metrics include Revenue, Total Bookings, Occupancy %, Cancellation %, Average Rating, Total Capacity, and Successful Bookings.

🔍 Key Insights
Delhi recorded one of the highest occupancy rates among the cities, while Bangalore had comparatively lower occupancy.

Presidential rooms had the highest occupancy among the different room classes.

Mumbai generated the highest revenue among the cities.

Weekend occupancy was higher compared with weekdays.

Third-party booking platforms contributed significantly to overall hotel bookings.
